# Política de segurança

Repositório **educacional e defensivo**. Todos os dados são sintéticos (IPs de documentação RFC 5737, coordenadas de um marco público, logs gerados por código).
Não há ferramenta ofensiva, exploit, malware nem envio real de mensagens; o "dead man's switch" do Lab 06 é uma simulação em memória.

Achou uma falha no código? Abra um Security Advisory privado neste repositório.
Não use as ideias daqui contra sistemas sem autorização por escrito do dono.
